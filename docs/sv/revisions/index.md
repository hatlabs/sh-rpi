# Hårdvaruversioner

## Introduktion

Den här sidan dokumenterar kortets olika versioner och länkar till kopplingsschemana. Hela historiken över konstruktionsfilerna finns i [GitHub-repositoriet SH-RPi-hardware](https://github.com/hatlabs/SH-RPi-hardware).


## Version 2.0.0

Ett helt omkonstruerat kort med en ny strömhanteringskrets.

- Standardformfaktor för Raspberry Pi HAT
- 3 × 20 F superkondensatorer
- Förbättrad strömbegränsning
- Förbättrad uteffektkapacitet

Kopplingsschema: [SH-RPi-2.0.0-schema.pdf](assets/SH-RPi-2.0.0-schematics.pdf)

## Version 1.0.0

Den första versionen som såldes på [hatlabs.fi](https://hatlabs.fi).

- Innehåller både en strömhanteringskrets med superkondensator och ett NMEA 2000-gränssnitt
- En enda superkondensator på 60 F
- Realtidsklocka som tillval

Kopplingsschema: [SH-RPi-1.0.0-schema.pdf](assets/SH-RPi-1.0.0-schema.pdf)
