# Erratas

En esta página se enumeran todos los fallos de hardware conocidos de las distintas revisiones del SH-RPi.

## Versión 2.0.0

- Los pines de entrada externa (conector de pines de 2×2 marcado con «E» y «P») están cortocircuitados a masa y no funcionan.
