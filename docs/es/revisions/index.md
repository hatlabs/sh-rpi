# Revisiones de hardware

## Introducción

En esta página se documentan las distintas revisiones de la placa y se ofrecen enlaces a los esquemas. El historial completo de los archivos de diseño está disponible en el [repositorio de GitHub SH-RPi-hardware](https://github.com/hatlabs/SH-RPi-hardware).


## Versión 2.0.0

Placa completamente rediseñada con un nuevo circuito de gestión de la alimentación.

- Formato estándar de HAT de Raspberry Pi
- Supercondensadores de 3 × 20 F
- Limitación de corriente mejorada
- Mayor capacidad de salida de potencia

Esquemas: [SH-RPi-2.0.0-schema.pdf](assets/SH-RPi-2.0.0-schematics.pdf)

## Versión 1.0.0

Primera versión vendida en [hatlabs.fi](https://hatlabs.fi).

- Incluye tanto un circuito de gestión de la alimentación con supercondensadores como una interfaz NMEA 2000
- Un único supercondensador de 60 F
- Reloj de tiempo real opcional

Esquemas: [SH-RPi-1.0.0-schema.pdf](assets/SH-RPi-1.0.0-schema.pdf)
