# Bekende hardwarefouten

Op deze pagina staan alle bekende hardwarefouten van de verschillende SH-RPi-versies.

## Versie 2.0.0

- De pinnen voor de externe ingangen (2×2-pins header met opdruk E en P) zijn kortgesloten met massa en werken niet.
