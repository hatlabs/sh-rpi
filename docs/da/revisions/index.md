# Hardwarerevisioner

## Introduktion

Denne side dokumenterer de forskellige kortrevisioner og indeholder links til kredsløbsdiagrammerne. Den fulde historik for designfilerne findes i [SH-RPi-hardware-repositoriet på GitHub](https://github.com/hatlabs/SH-RPi-hardware).


## Version 2.0.0

Fuldstændigt redesignet kort med et nyt strømstyringskredsløb.

- Standardformfaktor for Raspberry Pi HAT
- 3 × 20 F superkondensatorer
- Forbedret strømbegrænsning
- Forbedret udgangseffekt

Kredsløbsdiagrammer: [SH-RPi-2.0.0-schema.pdf](assets/SH-RPi-2.0.0-schematics.pdf)

## Version 1.0.0

Den første version, der blev solgt på [hatlabs.fi](https://hatlabs.fi).

- Indeholder både et strømstyringskredsløb med superkondensator og en NMEA 2000-grænseflade
- Én superkondensator på 60 F
- Realtidsur som ekstraudstyr

Kredsløbsdiagrammer: [SH-RPi-1.0.0-schema.pdf](assets/SH-RPi-1.0.0-schema.pdf)
