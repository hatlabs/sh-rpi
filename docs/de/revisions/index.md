# Hardware-Revisionen

## Einleitung

Diese Seite dokumentiert die verschiedenen Platinenrevisionen und verlinkt die Schaltpläne. Die vollständige Historie der Designdateien ist im [GitHub-Repository SH-RPi-hardware](https://github.com/hatlabs/SH-RPi-hardware) verfügbar.


## Version 2.0.0

Vollständig neu entwickelte Platine mit neuer Energieverwaltungsschaltung.

- Standard-Formfaktor eines Raspberry-Pi-HAT
- 3 × 20 F Superkondensatoren
- Verbesserte Strombegrenzung
- Verbesserte Ausgangsleistung

Schaltpläne: [SH-RPi-2.0.0-schema.pdf](assets/SH-RPi-2.0.0-schematics.pdf)

## Version 1.0.0

Erste bei [hatlabs.fi](https://hatlabs.fi) verkaufte Version.

- Enthält sowohl eine Energieverwaltungsschaltung mit Superkondensator als auch eine NMEA-2000-Schnittstelle
- Ein einzelner Superkondensator mit 60 F
- Optionale Echtzeituhr

Schaltpläne: [SH-RPi-1.0.0-schema.pdf](assets/SH-RPi-1.0.0-schema.pdf)
