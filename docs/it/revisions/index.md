# Revisioni hardware

## Introduzione

Questa pagina documenta le diverse revisioni della scheda e fornisce i collegamenti agli schemi elettrici. La cronologia completa dei file di progetto è disponibile nel [repository GitHub SH-RPi-hardware](https://github.com/hatlabs/SH-RPi-hardware).


## Versione 2.0.0

Scheda completamente riprogettata, con un nuovo circuito di gestione dell’alimentazione.

- Formato standard degli HAT per Raspberry Pi
- Supercondensatori 3× 20 F
- Limitazione di corrente migliorata
- Maggiore capacità di erogazione in uscita

Schemi elettrici: [SH-RPi-2.0.0-schema.pdf](assets/SH-RPi-2.0.0-schematics.pdf)

## Versione 1.0.0

Prima versione venduta su [hatlabs.fi](https://hatlabs.fi).

- Comprende sia un circuito di gestione dell’alimentazione a supercondensatori sia un’interfaccia NMEA 2000
- Un solo supercondensatore da 60 F
- Orologio in tempo reale opzionale

Schemi elettrici: [SH-RPi-1.0.0-schema.pdf](assets/SH-RPi-1.0.0-schema.pdf)
