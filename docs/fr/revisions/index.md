# Révisions matérielles

## Introduction

Cette page documente les différentes révisions de la carte et donne accès aux schémas. L'historique complet des fichiers de conception est disponible dans le [dépôt GitHub SH-RPi-hardware](https://github.com/hatlabs/SH-RPi-hardware).


## Version 2.0.0

Carte entièrement repensée, avec un nouveau circuit de gestion de l'alimentation.

- Format HAT Raspberry Pi standard
- Supercondensateurs 3 × 20 F
- Limitation de courant améliorée
- Capacité de sortie en puissance améliorée

Schémas : [SH-RPi-2.0.0-schema.pdf](assets/SH-RPi-2.0.0-schematics.pdf)

## Version 1.0.0

Première version vendue sur [hatlabs.fi](https://hatlabs.fi).

- Comprend à la fois un circuit de gestion de l'alimentation à supercondensateurs et une interface NMEA 2000
- Un seul supercondensateur de 60 F
- Horloge temps réel en option

Schémas : [SH-RPi-1.0.0-schema.pdf](assets/SH-RPi-1.0.0-schema.pdf)
